固定文字共 161 个点位采用同一编辑/读取机制，已做点位白名单与数据契约检查；未宣称逐条人工改写全部 161 个文案。15 个图片点位均实际选择替换，页面输出核对不是全页面逐图视觉重审。本次不重做既有网站的视觉设计，也不替代整个网站的 SEO/邮件验收。

## 本轮发现并修复

1. 产品编辑只改文字时，空文件输入被误认为已上传图片，导致原图引用丢失。修复后实际重新打开仍保留原图，换图和移除也验证。
2. 产品旧排序箭头只加减 1，容易与其它产品顺序相同。改为明确数字排序，数字越小越靠前；真实修改后列表首位变化并持久保存。
3. Windows standalone 绑定 127.0.0.1 时，语言改写被框架规范化为 localhost，造成内部代理循环或英文回退。保留原请求地址后，11 种语言的已发布标题均通过浏览器验证。

上述三个问题均先用回归测试复现失败，再修改并验证通过。全套 `node --test tests/*.node.mjs tests/*.test.mjs` 为 59/59；Windows `npm run build:windows` 完成，含 TypeScript 检查。

## 隔离及清理

- 设备/图文/参数发布走真实数据库和 RPC，但本机测试进程只读取同租户随机临时内容 key；不覆盖原 `gymetal-site-v1`。
- 原正式内容和未发布的 4 个历史语言字段完整回读一致。两轮临时内容、关联版本、短时会话均清理。
- 产品操作仅针对 `CODEX-E2E-PRODUCT-A`，上架验证后立即下架并删除；该临时产品曾短时处于已上架状态。客户原有产品逐行比较未变化，测试产品为 0。
- 3 个测试上传对象在解除全部引用后精确清理，R2 HEAD 确认不存在；临时媒体记录为 0。
- 本机测试服务及任务创建的浏览器会话关闭，未关闭负责人原有 Chrome。

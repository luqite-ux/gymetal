# 无锡广跃金属科技环境变量与第三方服务清单

生成日期：2026-10-05

本文仅记录变量名称和用途，不包含真实密钥。生产值保存在服务器 `.env.production.local`，不得提交 Git 或粘贴到普通交付文档。

## 环境变量

| 变量 | 用途 | 是否敏感 |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | 客户 Supabase API 地址 | 否 |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase 匿名公开访问 Key，受 RLS 限制 | 公开客户端变量 |
| `NEXT_PUBLIC_TENANT_ID` | 广跃租户 ID，用于租户隔离 | 否 |
| `SUPABASE_SERVICE_ROLE_KEY` | 后台登录、管理写入、询盘和验证码服务端操作 | 是，仅服务端 |
| `CAPTCHA_SECRET` | 询盘验证码 HMAC 签名密钥 | 是，仅服务端 |
| `CAPTCHA_SITE_SCOPE` | 本站验证码作用域，用于不同网站之间隔离 | 是，仅服务端 |
| `R2_S3_ENDPOINT` | Cloudflare R2 S3 兼容接口地址 | 否 |
| `R2_ACCESS_KEY_ID` | R2 API Access Key | 是，仅服务端 |
| `R2_SECRET_ACCESS_KEY` | R2 API Secret | 是，仅服务端 |
| `R2_BUCKET_NAME` | 当前媒体存储桶名称 | 配置项 |
| `R2_PUBLIC_URL_PREFIX` | 已发布媒体的公网 URL 前缀 | 否 |
| `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` | Google Search Console 站点验证 | 否 |
| `NEXT_PUBLIC_BING_SITE_VERIFICATION` | Bing Webmaster 站点验证 | 否 |
| `NEXT_PUBLIC_YANDEX_VERIFICATION` | Yandex Webmaster 站点验证 | 否 |
| `DEPLOYMENT_COMMIT_SHA` | 当前服务器部署采用的 Git commit；供 `/api/version` 回读 | 否 |
| `HOSTNAME` | Node 服务监听地址，服务器建议 `127.0.0.1` | 否 |
| `PORT` | Node 服务端口，当前约定 `3000` | 否 |

## 第三方服务与费用边界

| 服务 | 当前用途 | 账号/账单状态 | 当前结论 |
|---|---|---|---|
| 新网云服务器 | Windows、Node.js、Caddy 和网站运行 | 客户资源，费用由客户承担 | 待取得云服务器管理入口后切换新版本 |
| 新网域名 | `gymetaltech.com` 注册与 DNS | 客户资源 | 本次不修改 DNS/Nameserver |
| Supabase | PostgreSQL 数据库与 API | 客户已创建项目；界面曾显示 Free Plan | 数据已迁入；账单主体、区域和到期情况需客户控制台确认 |
| Cloudflare R2 | 网站文章/媒体文件 | 当前仍使用原共享资源 | **阻塞：客户需自行开通 R2 并完成付款信息** |
| GitHub | 源码和版本历史 | 当前仓库归公司账号 `luqite-ux` | 已提供完整 Git Bundle；如需客户所有权，需客户提供 GitHub 账号后转移或镜像 |
| Caddy | HTTPS 与反向代理 | 开源软件，无许可证费用 | 配置示例已交付；实际服务器配置待回读 |
| Google/Bing/Yandex | 搜索引擎站点验证 | 仅在对应变量配置时使用 | 无代码侧固定付费 |

## 密钥交接原则

1. 普通文档、Git 和聊天中不写真实密钥。
2. `.env.production.local` 只通过私密部署包交给服务器管理员。
3. 客户 R2 开通后，在客户账号中新建最小权限密钥，再更新服务器环境变量。
4. 新 R2 验证通过后才能撤销旧共享密钥；在此之前不得中断线上图片访问。

# 广跃网站部署说明

部署目录：`D:\www\gymetaltech`

1. 解压部署包并覆盖网站源码，但不要删除服务器已有的持久化文件。
2. 确认根目录存在 `.env.production.local`，再执行生产构建；缺少该文件时禁止继续部署。
3. 首次部署、`package.json` 或 `package-lock.json` 发生变化时执行 `npm ci`；只有业务代码变化且依赖已安装时可跳过。
4. 执行 `npm run build`，构建成功后重启 Node.js 服务。Caddy 配置未变化时无需重启 Caddy。
5. 重启后检查 `/news`、`/zh/news`、`/api/captcha?scope=deployment_check_1234567890` 和联系页，确认新闻有真实内容、验证码能够显示。

生产环境配置包含服务端密钥，只能随本地部署包安全交付；禁止提交 GitHub、粘贴到聊天记录或写入普通日志。

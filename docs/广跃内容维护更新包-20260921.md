# 广跃内容维护更新包

当前交付版本为 `gymetaltech-content-maintenance-20260921-r2.zip`。请勿继续使用不带 `-r2` 的早期包。

## 本次变化

后台入口 `/admin/content`，原 `/admin/pages` 自动转入新入口。可维护 23 台现有设备、161 个固定文案点位、15 个页面图片点位及 6 个参数；支持设备新增、编辑、移除、排序和上下架。保留原有 11 种语言与固定布局，不提供拖拽布局、HTML 或 CSS 编辑。

“保存草稿”仅保存后台工作，不改变访客看到的页面。“发布全部草稿”一次发布设备与固定页面的全部已保存修改。历史版本恢复先进入草稿，仍需发布。图片替换或移除不会物理删除旧图，保护已发布内容和历史版本。图片限 JPG、PNG、WebP，单张不超过 5MB。

产品仍走原有独立产品管理，本次没有把其改成上述整站草稿模式；修复了产品换图/保存失败时误删旧图风险。现有翻译能力未删除；新内容页可手工维护各语言，本次未新增一键翻译按钮。

## 数据状态

已仅为广跃租户初始化 `gymetal-site-v1`。正式快照保持原前台资料；原旧页面后台中与前台不同的 2 个文案、共 4 个中英文字段，保留在未发布草稿。部署不会自动发布这些差异。旧 pages 数据没有删除。不要为验收直接点击“发布全部草稿”，以免一起发布这些历史修改。

## 部署与回退

本包为源码更新包，不含密钥、环境文件、node_modules 或构建缓存。尚未部署客户服务器；不要部署到 Vercel，也不要改共享后台。

1. 备份现有 `D:\www\gymetaltech` 和服务启动参数，保留可恢复的完整旧目录。
2. 在新的候选目录解压本包；从客户服务器原目录保留其现有 `.env*` 配置。不要用本机配置覆盖邮件、验证码、数据库或 R2 配置，不改 Caddy/DNS。
3. Node.js 24 下执行 `npm ci`、`npm run build:windows`。构建需要可访问 Google Fonts。构建完成执行：

```powershell
Copy-Item -Recurse -Force .next\static .next\standalone\.next\static
Copy-Item -Recurse -Force public .next\standalone\public
$env:HOSTNAME="127.0.0.1"
$env:PORT="3000"
node --env-file=.env.production.local .next\standalone\server.js
```

实际服务管理方式沿用原服务器；确认启动环境与原服务一致。先在候选目录用空闲本机端口验证，成功后停旧进程、切换服务工作目录并启动，避免新旧 `.next` 文件混用。失败则切回完整旧目录和原服务参数，不删除数据库内容。
